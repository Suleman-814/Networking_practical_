#  Networking Practical Repository

A collection of **Cisco Packet Tracer (.pkt)** lab files covering essential networking concepts and practical assignments. This repository is designed for students, beginners, and anyone preparing for networking practical.

##  Topics Covered

- IP Address Configuration
- Basic Router & Switch Configuration
- Console Configuration
- VLAN Configuration
- Inter-VLAN Routing
- DHCP Configuration
- DNS Configuration
- Telnet Configuration
- RIP Routing
- Port Security
- IPv6 Configuration
- Network Troubleshooting

##  Included Packet Tracer Files

- `dhcp&telnet assignment.pkt`
- `inter vlan routing assignment (s).pkt`
- `ip basic assignment (cnsole)11.pkt`
- `port security assignment.pkt`
- `practice ipv6.pkt`
- `rip command assignment.pkt`

> More networking practical files will be added over time.

##  Requirements

- Cisco Packet Tracer 8.0 or later
- Basic knowledge of networking concepts

##  Purpose

This repository is intended to help:

- Networking students
- CCNA beginners
- Practice networking configurations
- Complete academic assignments
- Improve hands-on networking skills
